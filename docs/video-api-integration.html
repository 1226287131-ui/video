01 · Foundation

公共约定

鉴权、路径和字段格式先统一，模型卡片只描述差异部分。

不要重复拼接 /v1

如果 SDK Base URL 已设置为 https://api.kkone.vip/v1，创建路径应填写 videos 或 video/generations。

LegacyJSON

旧视频接口

POST /v1/video/generations
用于 video-v1。

ResourceJSON

OpenAI Video 资源接口

POST /v1/videos
用于 MiniMax-H3、video-v2、video-v2-fast 和 video-v3。

MultipartFORM

Grok 文件协议

POST /v1/videos
使用真实文件字段 input_reference。

02 · Lifecycle

任务流程

创建成功不等于视频完成。请保存任务 ID，并在终态后读取结果地址。

提交创建请求携带 Bearer Token 和对应模型协议的请求体。
保存 task_id优先读取 task_id，没有时回退 id。
轮询状态建议每 4-5 秒查询，直到 completed 或 failed。
读取结果按 result_url → video_url → url → metadata.url 读取。

04 · Media

参考素材上传

下游已有 CDN 时直接传公网 URL；没有 CDN 时使用项目临时上传服务。

临时外链接口

POST https://video.kkone.vip/api/uploads，使用 multipart/form-data 的 files 字段。

  • 服务端硬上限：图片 20MB、视频 200MB、音频 50MB。
  • 临时 URL 约保留 12 小时，每 12 小时自动清理。
  • v1/v2/v3 等 JSON 协议把返回的 url 放入对应数组。

按模型区分提交方式

  • video-v1：images[] URL，最多 9 张。
  • video-v2、video-v2-fast：images[] / videos[] / audios[]，最多 9 图、3 视频、3 音频。
  • video-v3：最多 30 图、10 视频、10 音频；字段形态取决于所选协议。
  • MiniMax-H3：images[] / reference_videos[] / reference_audios[]，最多 9 图、3 视频、3 音频。
  • grok-imagine-1.5-video：必须重新读取真实图片 Blob，并重复附加 input_reference 文件字段。
上传并获得公网 URL
curl --request POST "https://video.kkone.vip/api/uploads" \
  --header "Accept: application/json" \
  --form "files=@./reference.png;type=image/png"
响应中的 files[].url 只用于临时任务素材，不是永久文件存储。
05 · Response

响应、轮询与结果

兼容网关可能把任务包在 data 中，客户端应同时兼容对象和包装对象。

创建响应

保存 task_id，没有时读取 id。初始状态通常为 queued。

JSON
{
  "id": "task_a1b2c3d4",
  "task_id": "task_a1b2c3d4",
  "object": "video",
  "status": "queued",
  "progress": 0
}

成功结果

优先使用网关缓存的 result_url；它适合直接播放、下载和分享，视频最多保留 48 小时。

JSON
{
  "status": "completed",
  "progress": 100,
  "result_url": "https://api.kkone.vip/video-cache/task_a1b2c3d4.mp4",
  "metadata": { "url": "..." }
}
查询任务与鉴权内容回退
const baseUrl = 'https://api.kkone.vip'
const taskUrl = `${baseUrl}/v1/videos/${encodeURIComponent(taskId)}`
const response = await fetch(taskUrl, {
  headers: { Authorization: `Bearer ${apiKey}`, Accept: 'application/json' },
})
const task = await response.json()
const status = String(task.status || '').toLowerCase()
if (['success', 'succeeded', 'completed'].includes(status)) {
  const videoUrl = task.result_url || task.video_url || task.url || task.metadata?.url
}
// 没有公开结果链接时，使用同一模型对应的 /content 并携带 Bearer Token。
06 · Reliability

错误处理

错误信息要落到模型字段上，避免把一个模型的参数复制到另一个模型。

HTTP常见原因处理建议
400 / 422字段缺失、时长/画幅不支持、素材数量越界、Prompt 为空先按对应模型卡片核对字段名与取值。
401API Key 缺失、过期或格式错误使用 Authorization: Bearer <API_KEY>，不要放 URL。
403令牌或分组未开通模型确认模型映射和渠道权限。
413单文件或请求体超过网关限制压缩媒体，或改用可公开访问的 CDN URL。
429 / 5xx限流、上游繁忙、网关暂时异常降低并发；已有 task_id 时先查询，不要立即重复创建。
常见字段混用

grok-imagine-1.5-video 只接受 multipart 的 input_reference 文件；不要发送 JSON 的 images。

video-v3 原协议不能发送 size、start_frame_url 或 end_frame_url；这些字段仅属于 QY 兼容协议。QY 的首帧或尾帧 URL 不能与 images 同时发送。

MiniMax-H3 当前网页使用 seconds / size 和 images / reference_videos / reference_audios；不发送 reference_video_audios、mode、clarity、resolution、aspect_ratio、megapixels 或 metadata.multiple。

安全与保存

API Key 不要写入公开前端源码、仓库或查询参数。参考 URL 必须无需登录即可被上游访问。视频结果最长保留 48 小时，完成后请及时下载或转存。

01付费购买中转站 API注册、登录、领取试用额度与余额查看
  • 访问 https://api.kkone.vip/，点击注册。
  • 创建账号：使用 QQ 邮箱注册。
  • 登录账号，填写你的账号和密码，进行账号登录。
  • 加站长微信进入交流群，新人赠送 10 刀额度使用。
  • 新人找这个帅气的站长领取新人额度试用。
  • 额度查看：选择个人资料查看当前余额。
02创建 API 秘钥设置名称、分组和图片模型权限
  • 选择 API 秘钥进行创建。
  • 参数填写：名称随便写，例如 api；分组选择“稳定版企业级 1.5 倍率最稳定”，选择后点击保持更改。
  • 同时把支持图片模型 API 勾选，进行保存更改。
03下载 CC Switch 软件获取并安装客户端配置工具
  • 访问 https://github.com/farion1231/cc-switch/releases，点开更多，如箭头图示。
  • Windows 用户选择 CC-Switch-v3.18.0-Windows.msi 版本进行下载。
  • 备注：原教程标注 MAC 用户选择 CC-Switch-v3.18.0-Windows.dmg 版本下载。
  • 下载完成后点击软件安装，随后启动客户端显示界面。

原教程附带的安装包标记为 CC-Switch-v3.18.0-Windows (1).msi，大小 12.25MB。

04导入已创建的秘钥在 CC Switch 中一键配置并启用 Codex
  • 点击创建完成的 API 秘钥，选择图示右边三个点；确认分组支持图片模型使用，选择 CC Switch 一键导入。
  • 弹窗窗口界面选择 Codex，搜索 5.6，选择 gpt-5.6-sol 模型，点击打开 CC Switch。
  • 选择打开 CC Switch。
  • 触发 CC Switch 客户端，一键自动配置，选择导入。
  • 先检测配置是否连接成功，如图示。
  • 选择启用；启用后会显示使用中。
05下载并设置 ChatGPT 客户端客户端安装、中文界面与项目创建
  • 科学上网开启全局代理。
  • 访问 ChatGPT 下载客户端网站。下载方式 1：微软商店下载，网址为 apps.microsoft.com/detail/9plm9xgg6vks。
  • 下载方式 2：第三方平台（没有科学上网推荐选择这个），网址为 https://codexapp.agentsmirror.com/。
  • 打开安装包运行，显示更新后点击更新，等待更新下载完成。
  • 更新完成会自动打开软件，选择完成设置。
  • 中文设置：选择设置，如图示；选择语言切换；搜索中文，选择中文配置；配置成功后选择返回应用。
  • 界面启动后选择项目，点击新建项目；创建项目，给项目创建名称，选择创建项目。

原教程附带的客户端安装包标记为 ChatGPT Installer.exe（1.40MB）和 CodexAppManager_x64-setup.exe（4.73MB）。

06测试 API 配置是否成功发起一条提示词，确认客户端已完成中转站配置
  • 输入提示词：你好，你是什么模型。
  • 配置显示这样的对话，代表已经完成中转站配置 Codex 使用，如图示。
